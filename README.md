# 🏥 Hospital Emergency Room Data Analysis – Excel

## 📌 Project Overview
An Excel-based data analysis project focused on understanding hospital emergency room performance, patient visits, waiting times, and admission trends through an interactive dashboard.

## 📊 Key Insights
- Total Number of Patients
- Average Patient Wait Time
- Admission vs. Non-Admission Status
- Patient Age Distribution
- Gender Analysis
- Department Referrals
- Percentage of Patients Seen Within 30 Minutes

## 🛠️ Tools Used
- Microsoft Excel
- Data Cleaning
- Pivot Tables & Charts
- Interactive Dashboard
- Data Visualization
